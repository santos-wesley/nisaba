#MP-Declare Model
## Activities
- **Plan Event**: The 'Plan Event' activity represents the initial planning phase for organizing an event, including defining the event details and budget.
- **Book Venue**: The 'Book Venue' activity involves reserving a specific venue for the event based on the event plan.
- **Send Invitations**: The 'Send Invitations' activity entails dispatching invitations to guests and tracking the invitation status.
- **Arrange Catering**: The 'Arrange Catering' activity involves organizing the catering service for the event, selecting the appropriate catering type.
- **Hire Staff**: The 'Hire Staff' activity consists of recruiting staff members for various roles required during the event.
- **Set Up Venue**: The 'Set Up Venue' activity involves preparing and configuring the venue space before the event takes place.
- **Conduct Rehearsal**: The 'Conduct Rehearsal' activity entails running a rehearsal session to ensure all event logistics and roles are well-coordinated.
- **Welcome Guests**: The 'Welcome Guests' activity involves greeting and receiving guests as they arrive at the event venue.
- **Facilitate Activities**: The 'Facilitate Activities' activity consists of managing and coordinating the various activities scheduled during the event.
- **Deliver Speech**: The 'Deliver Speech' activity involves presenting a speech to the attendees during the event.
- **Serve Meals**: The 'Serve Meals' activity entails providing food to guests using the arranged catering service.
- **Coordinate Photography**: The 'Coordinate Photography' activity involves managing photography services to capture moments during the event.
- **Distribute Gifts**: The 'Distribute Gifts' activity consists of handing out gifts to guests as part of the event proceedings.
- **Tear Down Venue**: The 'Tear Down Venue' activity involves dismantling and clearing the venue after the event has concluded.
- **Collect Feedback**: The 'Collect Feedback' activity includes gathering feedback from guests and staff about the event.

## Attributes
- **Event ID: integer between 1 and 999999**: The attribute 'Event ID: integer between 1 and 999999' represents the unique identification number assigned to each event.
- **Venue: Hall A, Hall B, Hall C**: The attribute 'Venue: Hall A, Hall B, Hall C' specifies the available venue options for hosting the event.
- **Catering Service: Buffet, Sit-down Dinner, Cocktail**: The attribute 'Catering Service: Buffet, Sit-down Dinner, Cocktail' specifies the types of catering services available for the event.
- **Number of Guests: integer between 10 and 500**: The attribute 'Number of Guests: integer between 10 and 500' represents the expected number of guests attending the event.
- **Invitation Status: Sent, Not Sent**: The attribute 'Invitation Status: Sent, Not Sent' indicates whether the invitations have been sent or not.
- **Staff Role: Waiter, Coordinator, Cleaner**: The attribute 'Staff Role: Waiter, Coordinator, Cleaner' specifies the possible roles assigned to hired staff members.
- **Rehearsal ID: integer between 1 and 9999**: The attribute 'Rehearsal ID: integer between 1 and 9999' represents the unique identification number assigned to each rehearsal session.
- **Budget: float between 1000 and 50000**: The attribute 'Budget: float between 1000 and 50000' represents the allocated financial budget for the event.

## Interleaved Description
The MP-Declare process model for the event organization process is described as follows:

### **Trace-Related Constraints**
#### **Init Constraints**
The process begins with the activity 'Plan Event,' which involves defining the event details and budget. This activity requires the 'Event ID' and 'Budget' attributes, where the Event ID is a unique identification number between 1 and 999999, and the Budget is a float between 1000 and 50000, representing the allocated financial resources for the event. This initial planning phase establishes the foundational context for all subsequent event organization activities.

#### **End Constraints**
The process concludes with the activity 'Tear Down Venue,' which involves dismantling and clearing the venue after the event has concluded. This activity must be the last to occur in the process, ensuring that all event-related activities are completed before the venue is restored to its original state, thereby closing the process coherently.
