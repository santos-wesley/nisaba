## Activities
- **Monitor Store Entrance**: The 'Monitor Store Entrance' activity represents the continuous observation of the store's entrance to detect any suspicious behavior or unauthorized access.
- **Inspect Security Cameras**: The 'Inspect Security Cameras' activity involves checking the functionality and footage of security cameras to ensure proper surveillance.
- **Conduct Bag Check**: The 'Conduct Bag Check' activity includes inspecting customers' bags for potential security threats or stolen items.
- **Alert Security Personnel**: The 'Alert Security Personnel' activity entails notifying security staff about a potential security issue or incident.
- **Review Security Footage**: The 'Review Security Footage' activity involves analyzing recorded video from security cameras to investigate incidents.
- **Report Incident**: The 'Report Incident' activity consists of documenting and reporting any security breaches or suspicious activities.
- **Escort Suspect**: The 'Escort Suspect' activity involves safely guiding a suspected individual to a secure area or out of the premises.
- **Verify Alarm Trigger**: The 'Verify Alarm Trigger' activity includes confirming whether an alarm activation is legitimate or a false positive.
- **Perform Security Audit**: The 'Perform Security Audit' activity entails evaluating the overall security measures and identifying vulnerabilities.
- **Update Security Protocols**: The 'Update Security Protocols' activity involves revising and improving the existing security procedures and guidelines.
- **Train Security Staff**: The 'Train Security Staff' activity consists of educating and preparing security personnel on new protocols and skills.
- **Handle Customer Complaint**: The 'Handle Customer Complaint' activity involves addressing and resolving issues raised by customers regarding security or service.
- **Check Inventory Discrepancies**: The 'Check Inventory Discrepancies' activity includes investigating mismatches between recorded and actual inventory levels.
- **Conduct Emergency Drill**: The 'Conduct Emergency Drill' activity entails practicing emergency response procedures with the staff.
- **Deactivate Alarm**: The 'Deactivate Alarm' activity involves turning off the alarm system after verification or resolution of the trigger.

## Attributes
- **Camera ID: integer between 1 and 1000**: The attribute 'Camera ID: integer between 1 and 1000' represents the unique identification number assigned to each security camera in the store.
- **Incident Severity: float between 0.1 and 10.0**: The attribute 'Incident Severity: float between 0.1 and 10.0' indicates the level of seriousness of a reported security incident, ranging from minor to critical.
- **Alarm Status: Active, Inactive, Triggered**: The attribute 'Alarm Status: Active, Inactive, Triggered' specifies the current state of the alarm system, which can be active, inactive, or triggered.
- **Security Level: Low, Medium, High**: The attribute 'Security Level: Low, Medium, High' denotes the urgency or priority level for alerting security personnel, categorized as low, medium, or high.
- **Personnel ID: integer between 1 and 500**: The attribute 'Personnel ID: integer between 1 and 500' represents the unique identification number for each security personnel member.
- **Incident Type: Theft, Vandalism, Assault**: The attribute 'Incident Type: Theft, Vandalism, Assault' classifies the nature of the security incident, such as theft, vandalism, or assault.
- **Customer ID: integer between 1 and 10000**: The attribute 'Customer ID: integer between 1 and 10000' is the unique identifier for each customer involved in bag checks or complaints.
- **Audit Score: float between 0.0 and 100.0**: The attribute 'Audit Score: float between 0.0 and 100.0' quantifies the results of a security audit, expressed as a percentage from 0 to 100.
- **Complaint Status: Resolved, Unresolved**: The attribute 'Complaint Status: Resolved, Unresolved' indicates whether a customer complaint has been addressed and closed or remains open.
