## Activities
- **Monitor Store Entrance**: The 'Monitor Store Entrance' activity involves overseeing and observing the entry points of the store to ensure security.
- **Inspect Security Cameras**: The 'Inspect Security Cameras' activity includes checking and examining the security camera systems for proper functioning.
- **Conduct Bag Check**: The 'Conduct Bag Check' activity involves inspecting customers' bags for prohibited items or suspicious content.
- **Alert Security Personnel**: The 'Alert Security Personnel' activity includes notifying security staff about potential security threats or incidents.
- **Review Security Footage**: The 'Review Security Footage' activity involves analyzing recorded video from security cameras to identify incidents.
- **Report Incident**: The 'Report Incident' activity includes documenting and reporting any security incidents that occur in the store.
- **Escort Suspect**: The 'Escort Suspect' activity involves accompanying a suspected individual out of the premises or to a secure area.
- **Verify Alarm Trigger**: The 'Verify Alarm Trigger' activity includes confirming whether an alarm activation is genuine or a false alarm.
- **Perform Security Audit**: The 'Perform Security Audit' activity involves conducting a comprehensive evaluation of the store's security measures.
- **Update Security Protocols**: The 'Update Security Protocols' activity includes revising and improving security procedures based on audit findings.
- **Train Security Staff**: The 'Train Security Staff' activity involves providing training sessions to security personnel on procedures and protocols.
- **Handle Customer Complaint**: The 'Handle Customer Complaint' activity includes addressing and resolving complaints raised by customers.
- **Check Inventory Discrepancies**: The 'Check Inventory Discrepancies' activity involves investigating differences between recorded and actual inventory levels.
- **Conduct Emergency Drill**: The 'Conduct Emergency Drill' activity includes performing practice exercises for emergency situations.
- **Deactivate Alarm**: The 'Deactivate Alarm' activity involves turning off an alarm system after it has been triggered and verified.

## Attributes
- **Camera ID: integer between 1 and 1000**: The attribute 'Camera ID: integer between 1 and 1000' represents the unique identification number assigned to each security camera in the system.
- **Incident Severity: float between 0.1 and 10.0**: The attribute 'Incident Severity: float between 0.1 and 10.0' represents the severity level of a reported security incident.
- **Alarm Status: Active, Inactive, Triggered**: The attribute 'Alarm Status: Active, Inactive, Triggered' specifies the current state of an alarm system.
- **Security Level: Low, Medium, High**: The attribute 'Security Level: Low, Medium, High' defines the clearance or authorization level of security personnel.
- **Personnel ID: integer between 1 and 500**: The attribute 'Personnel ID: integer between 1 and 500' represents the unique identification number assigned to each security staff member.
- **Incident Type: Theft, Vandalism, Assault**: The attribute 'Incident Type: Theft, Vandalism, Assault' specifies the category of a reported security incident.
- **Customer ID: integer between 1 and 10000**: The attribute 'Customer ID: integer between 1 and 10000' represents the unique identification number assigned to each customer.
- **Audit Score: float between 0.0 and 100.0**: The attribute 'Audit Score: float between 0.0 and 100.0' represents the numerical score resulting from a security audit evaluation.
- **Complaint Status: Resolved, Unresolved**: The attribute 'Complaint Status: Resolved, Unresolved' indicates whether a customer complaint has been resolved or remains open.
