#MP-Declare Model
## Activities
- **Prepare Sample**: The 'Prepare Sample' activity represents the preparation of a material sample for subsequent testing and analysis.
- **Conduct X-ray Diffraction**: The 'Conduct X-ray Diffraction' activity involves performing X-ray diffraction analysis on a sample to determine its structural properties.
- **Measure Hardness**: The 'Measure Hardness' activity includes measuring the hardness of a material sample.
- **Analyze Microstructure**: The 'Analyze Microstructure' activity involves examining the microstructure of a sample to identify its structural characteristics.
- **Perform Thermal Analysis**: The 'Perform Thermal Analysis' activity involves analyzing the thermal properties of a material sample.
- **Conduct Tensile Test**: The 'Conduct Tensile Test' activity involves testing a sample to determine its tensile strength.
- **Evaluate Corrosion Resistance**: The 'Evaluate Corrosion Resistance' activity involves assessing a sample's resistance to corrosion.
- **Perform Chemical Analysis**: The 'Perform Chemical Analysis' activity involves analyzing the chemical composition of a sample.
- **Document Results**: The 'Document Results' activity involves recording and documenting the results obtained from various tests and analyses.
- **Review Findings**: The 'Review Findings' activity involves reviewing the documented results and findings from the testing process.
- **Approve Material**: The 'Approve Material' activity represents the approval of a material based on the reviewed findings.
- **Reject Material**: The 'Reject Material' activity represents the rejection of a material based on the reviewed findings.
- **Store Sample**: The 'Store Sample' activity involves storing the material sample after testing and analysis.
- **Calibrate Equipment**: The 'Calibrate Equipment' activity involves calibrating the equipment used for testing and analysis to ensure accuracy.
- **Prepare Report**: The 'Prepare Report' activity involves compiling a report summarizing the results and findings of the testing process.

## Attributes
- **Sample ID: Integer between 1 and 1000**: The attribute 'Sample ID: Integer between 1 and 1000' represents the unique identification number assigned to a material sample.
- **Hardness Value: Float between 0.0 and 100.0**: The attribute 'Hardness Value: Float between 0.0 and 100.0' represents the measured hardness value of a material sample.
- **Tensile Strength: Float between 0.0 and 2000.0**: The attribute 'Tensile Strength: Float between 0.0 and 2000.0' represents the measured tensile strength of a material sample.
- **Corrosion Resistance: High, Medium, Low**: The attribute 'Corrosion Resistance: High, Medium, Low' specifies the level of corrosion resistance evaluated for a material sample.
- **Approval Status: Approved, Rejected, Pending**: The attribute 'Approval Status: Approved, Rejected, Pending' specifies the current approval state of a material sample.
- **Thermal Conductivity: Float between 0.0 and 500.0**: The attribute 'Thermal Conductivity: Float between 0.0 and 500.0' represents the measured thermal conductivity of a material sample.
- **Microstructure Type: Grain, Fiber, Amorphous**: The attribute 'Microstructure Type: Grain, Fiber, Amorphous' specifies the type of microstructure identified in a material sample.
- **Chemical Purity: Float between 0.0 and 100.0**: The attribute 'Chemical Purity: Float between 0.0 and 100.0' represents the measured chemical purity level of a material sample.
- **Equipment Status: Calibrated, Not Calibrated**: The attribute 'Equipment Status: Calibrated, Not Calibrated' specifies whether the equipment used for testing and analysis is calibrated.

## Constraints
- **Init[Prepare Sample] | |**: The 'Prepare Sample' must be the first activity to occur in the process.
- **End[Approve Material] | |**: The 'Approve Material' must be the last activity to occur in the process.
- **End[Reject Material] | |**: The 'Reject Material' must be the last activity to occur in the process.
- **Response[Conduct X-ray Diffraction, Analyze Microstructure] | |A.Sample ID == T.Sample ID |0,2,h**: If a 'Conduct X-ray Diffraction' activity occurs, then an 'Analyze Microstructure' activity must eventually occur after the 'Conduct X-ray Diffraction' event at some point in the same process instance, where the 'Sample ID' of the 'Conduct X-ray Diffraction' event equals the 'Sample ID' of the 'Analyze Microstructure' event, and the 'Analyze Microstructure' event must occur within 0 to 2 hours after the 'Conduct X-ray Diffraction' event. Multiple 'Conduct X-ray Diffraction' events can be pending at the same time, and a single 'Analyze Microstructure' event can fulfill the obligation for all preceding 'Conduct X-ray Diffraction' events with matching 'Sample ID'. If 'Conduct X-ray Diffraction' does not occur, the constraint imposes no obligation on the occurrence of 'Analyze Microstructure'.
- **Chain Response[Measure Hardness, Conduct Tensile Test] | |A.Sample ID == T.Sample ID |0,1,h**: Whenever a 'Measure Hardness' activity occurs, it must be immediately followed by a 'Conduct Tensile Test' activity in the next event position, with no other events in between, where the 'Sample ID' of the 'Measure Hardness' event equals the 'Sample ID' of the 'Conduct Tensile Test' event, and the 'Conduct Tensile Test' event must occur within 0 to 1 hour after the 'Measure Hardness' event. The 'Conduct Tensile Test' activity is allowed to happen isolated.
- **Succession[Perform Thermal Analysis, Evaluate Corrosion Resistance] | |A.Sample ID == T.Sample ID |0,1,d**: A 'Perform Thermal Analysis' activity must be followed by an 'Evaluate Corrosion Resistance' activity at some point later in the same process instance, where the 'Sample ID' of the 'Perform Thermal Analysis' event equals the 'Sample ID' of the 'Evaluate Corrosion Resistance' event, and the 'Evaluate Corrosion Resistance' event must occur within 0 to 1 day after the 'Perform Thermal Analysis' event. Conversely, an 'Evaluate Corrosion Resistance' event can occur only if a 'Perform Thermal Analysis' event has occurred before it within the same process instance. This bidirectional and ordered dependency ensures that 'Perform Thermal Analysis' imposes obligations for future 'Evaluate Corrosion Resistance', and 'Evaluate Corrosion Resistance' cannot occur without prior 'Perform Thermal Analysis'. Multiple 'Perform Thermal Analysis' and 'Evaluate Corrosion Resistance' events are allowed, with each 'Perform Thermal Analysis' eventually leading to an 'Evaluate Corrosion Resistance' and each 'Evaluate Corrosion Resistance' being justified by a preceding 'Perform Thermal Analysis'.
- **Precedence[Document Results, Review Findings] | |A.Sample ID == T.Sample ID |**: The 'Review Findings' activity is permitted to occur only if a 'Document Results' activity has occurred before it within the same process instance, where the 'Sample ID' of the 'Document Results' event equals the 'Sample ID' of the 'Review Findings' event. Multiple 'Document Results' events can occur, and any number of events (including other 'Review Findings' events) can happen between a 'Document Results' event and a subsequent 'Review Findings' event.
- **Precedence[Approve Material, Review Findings] | |A.Sample ID == T.Sample ID |**: The 'Review Findings' activity is permitted to occur only if an 'Approve Material' activity has occurred before it within the same process instance, where the 'Sample ID' of the 'Approve Material' event equals the 'Sample ID' of the 'Review Findings' event.

- **Precedence[Conduct X-ray Diffraction, Calibrate Equipment] | |A.Equipment Status is Calibrated |**: The 'Calibrate Equipment' activity is permitted to occur only if a 'Conduct X-ray Diffraction' activity has occurred before it within the same process instance, where the 'Equipment Status' of the 'Calibrate Equipment' event is 'Calibrated'.
- **Precedence[Measure Hardness, Calibrate Equipment] | |A.Equipment Status is Calibrated |**: The 'Calibrate Equipment' activity is permitted to occur only if a 'Measure Hardness' activity has occurred before it within the same process instance, where the 'Equipment Status' of the 'Calibrate Equipment' event is 'Calibrated'.

## Interleaved Description
The MP-Declare process model for the material testing and analysis process is described as follows:

### **Trace-Related Constraints**

#### **Init Constraints**
The process begins with the activity 'Prepare Sample,' establishing the foundational context in which a material sample is readied for all subsequent testing and analysis. As the mandatory starting point, this activity, bound to the 'Sample ID' attribute, sets the stage for every other event that follows within the process instance.

#### **End Constraints**
Building toward closure, the process concludes with either of two mutually exclusive outcomes. In one path, the process ends with the activity 'Approve Material,' finalizing the material's status as accepted based on the reviewed findings. Alternatively, the process concludes with 'Reject Material,' finalizing the material's status as rejected. Whichever outcome occurs, it must be the last activity to take place, bringing coherent resolution to the testing process.

### **Dependency Constraints**

#### **Responded Existence Constraint**
Establishing a dependency between structural analyses, whenever a 'Conduct X-ray Diffraction' activity occurs, it necessitates the eventual occurrence of an 'Analyze Microstructure' activity for the same sample, identified by matching 'Sample ID' values. This 'Analyze Microstructure' event must take place within 0 to 2 hours after the 'Conduct X-ray Diffraction' event, and a single 'Analyze Microstructure' occurrence may satisfy the obligation for multiple preceding diffraction events on the same sample. However, if no diffraction analysis occurs, no such obligation is imposed, preserving flexibility in the model.

### **Flexible Ordering Constraints**

#### **Precedence Constraints**
Setting up the logical sequence of the process, several precedence relationships guide the order of activities. First, the 'Review Findings' activity is permitted to occur only if a 'Document Results' activity has occurred beforehand for the same sample, ensuring that findings are grounded in documented evidence before being reviewed. Building on this, 'Review Findings' further requires that either an 'Approve Material' or a 'Reject Material' activity has already taken place for the same sample, ensuring that the review process is contextualized by a definitive material decision.

In a parallel thread governing equipment integrity, the 'Calibrate Equipment' activity is permitted to occur only after specific testing activities have already taken place—namely, 'Conduct X-ray Diffraction,' 'Measure Hardness,' 'Conduct Tensile Test,' 'Perform Thermal Analysis,' or 'Evaluate Corrosion Resistance'—and, in each case, the 'Equipment Status' at the time of calibration must be 'Calibrated.' This establishes a foundational context wherein testing activities precede calibration checks, ensuring that equipment status is verified only after relevant testing has been performed.

Finally, the 'Document Results' activity is permitted to occur only if a 'Prepare Report' activity has occurred beforehand for the same sample, and this documentation must take place within 0 to 1 day after the report preparation, reinforcing a tightly guided temporal sequence between reporting and documentation.

#### **Response Constraints**
Defining an ordered temporal flow, whenever a 'Conduct X-ray Diffraction' activity occurs, it sets in motion an obligation for an 'Analyze Microstructure' activity to follow within 0 to 2 hours for the same sample, ensuring that structural diffraction data is promptly complemented by microstructural analysis.

#### **Succession Constraints**
Establishing a causal and bidirectional link between thermal and corrosion testing, a 'Perform Thermal Analysis' activity must eventually be followed by an 'Evaluate Corrosion Resistance' activity for the same sample, occurring within 0 to 1 day afterward. Conversely, an 'Evaluate Corrosion Resistance' event cannot occur unless it is preceded by a 'Perform Thermal Analysis' event for that same sample. This creates a cohesive progression in which thermal analysis and corrosion evaluation are causally intertwined, each justifying and necessitating the other within the same process instance.

### **Immediate Ordering Constraints**

#### **Chain Response Constraint**
Capturing an immediate cause-and-effect relationship, whenever a 'Measure Hardness' activity occurs, it must be directly and immediately followed by a 'Conduct Tensile Test' activity, with no other events intervening, for the same sample. This subsequent tensile test must occur within 0 to 1 hour of the hardness measurement, ensuring a tightly coupled sequence between these two mechanical assessments. Notably, 'Conduct Tensile Test' remains free to occur in isolation, without requiring a preceding hardness measurement, preserving flexibility elsewhere in the model.
