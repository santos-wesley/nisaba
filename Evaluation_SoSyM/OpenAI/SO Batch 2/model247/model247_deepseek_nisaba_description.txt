#MP-Declare Model
## Activities
- **File Patent Application**: The 'File Patent Application' activity represents the submission of a patent application to the intellectual property office.
- **Conduct Patent Search**: The 'Conduct Patent Search' activity involves searching existing patents to determine the novelty of the invention.
- **Examine Patent Application**: The 'Examine Patent Application' activity involves reviewing the patent application to assess its compliance with legal requirements.
- **Grant Patent**: The 'Grant Patent' activity represents the official approval and issuance of a patent.
- **Reject Patent Application**: The 'Reject Patent Application' activity represents the denial of a patent application.
- **File Trademark Application**: The 'File Trademark Application' activity represents the submission of a trademark application to the intellectual property office.
- **Conduct Trademark Search**: The 'Conduct Trademark Search' activity involves searching existing trademarks to determine potential conflicts.
- **Examine Trademark Application**: The 'Examine Trademark Application' activity involves reviewing the trademark application to assess its compliance with legal requirements.
- **Grant Trademark**: The 'Grant Trademark' activity represents the official approval and registration of a trademark.
- **Reject Trademark Application**: The 'Reject Trademark Application' activity represents the denial of a trademark application.
- **File Copyright Registration**: The 'File Copyright Registration' activity represents the submission of a copyright registration application.
- **Examine Copyright Application**: The 'Examine Copyright Application' activity involves reviewing the copyright application to assess its compliance with legal requirements.
- **Grant Copyright**: The 'Grant Copyright' activity represents the official approval and registration of a copyright.
- **Reject Copyright Application**: The 'Reject Copyright Application' activity represents the denial of a copyright registration application.
- **Appeal Decision**: The 'Appeal Decision' activity involves challenging a rejected application decision through a formal appeal process.

## Attributes
- **Application ID: integer between 1 and 1000000**: The attribute 'Application ID: integer between 1 and 1000000' represents the unique identification number assigned to each application.
- **Application Fee: float between 50.0 and 10000.0**: The attribute 'Application Fee: float between 50.0 and 10000.0' represents the fee amount required to be paid when filing an application.
- **Application Status: Pending, Approved, Rejected**: The attribute 'Application Status: Pending, Approved, Rejected' specifies the current status of an application, which can be pending review, approved, or rejected.
- **Search Result: Clear, Conflict**: The attribute 'Search Result: Clear, Conflict' indicates whether a search found no conflicting prior rights (Clear) or identified a potential conflict (Conflict).
- **Decision: Granted, Rejected**: The attribute 'Decision: Granted, Rejected' specifies the outcome of an examination, which can be either granted or rejected.

## Interleaved Description
The MP-Declare process model for the intellectual property application process is described as follows:

### **Trace-Related Constraints**
#### **Init Constraints**
The process begins with the activity 'File Patent Application,' which involves submitting a patent application to the intellectual property office with a unique 'Application ID' and a required 'Application Fee' attribute.

#### **End Constraints**
The process concludes with either the activity 'Grant Patent,' representing the official approval and issuance of a patent, or the activity 'Reject Patent Application,' representing the denial of a patent application. Both activities must be the last to occur in the process, ensuring a definitive outcome.

### **Frequency Constraints**
#### **Existence Constraints**
The 'Conduct Patent Search' activity must occur at least once in the process. This ensures that a search of existing patents is performed to determine the novelty of the invention, adding depth and reliability to the process.

### **Flexible Ordering Constraints**
#### **Precedence Constraints**
1. The activity 'Reject Patent Application' is permitted to occur only if an 'Appeal Decision' activity has occurred before it, with the correlation condition that the 'Application ID' of the 'Appeal Decision' equals the 'Application ID' of the 'Reject Patent Application.' This ensures that a rejection after an appeal is based on a formal review of the same application.
2. The activity 'Reject Trademark Application' is permitted to occur only if an 'Appeal Decision' activity has occurred before it, with the correlation condition that the 'Application ID' of the 'Appeal Decision' equals the 'Application ID' of the 'Reject Trademark Application.' This ensures that a trademark rejection after an appeal is based on a formal review of the same application.
3. The activity 'Reject Copyright Application' is permitted to occur only if an 'Appeal Decision' activity has occurred before it, with the correlation condition that the 'Application ID' of the 'Appeal Decision' equals the 'Application ID' of the 'Reject Copyright Application.' This ensures that a copyright rejection after an appeal is based on a formal review of the same application.

#### **Response Constraints**
1. If the 'Conduct Patent Search' activity occurs with the condition 'Search Result is Clear,' then the 'Examine Patent Application' activity must occur within 0 to 2 days. This ensures a timely examination of the patent application following a clear search result, maintaining the process's momentum.
2. If the 'Conduct Trademark Search' activity occurs with the condition 'Search Result is Clear,' then the 'Examine Trademark Application' activity must occur within 0 to 2 days. This ensures a timely examination of the trademark application following a clear search result, maintaining the process's momentum.
3. If the 'File Copyright Registration' activity occurs, then the 'Examine Copyright Application' activity must occur within 0 to 2 days. This ensures a timely examination of the copyright application after filing, maintaining the process's momentum.

### **Exclusivity Constraints**
#### **Choice Constraints**
1. If the 'Examine Patent Application' activity occurs with the condition 'Application Status is Approved,' then at least one of the activities 'Examine Patent Application' or 'Grant Patent' must occur within 0 to 1 days. This introduces an alternative path, allowing flexibility by permitting either the examination to continue or the patent to be granted directly.
2. If the 'Examine Patent Application' activity occurs with the condition 'Application Status is Rejected,' then at least one of the activities 'Examine Patent Application' or 'Reject Patent Application' must occur within 0 to 1 days. This introduces an alternative path, allowing flexibility by permitting either the examination to continue or the patent to be rejected directly.
3. If the 'Examine Trademark Application' activity occurs with the condition 'Application Status is Approved,' then at least one of the activities 'Examine Trademark Application' or 'Grant Trademark' must occur within 0 to 1 days. This introduces an alternative path, allowing flexibility by permitting either the examination to continue or the trademark to be granted directly.
4. If the 'Examine Trademark Application' activity occurs with the condition 'Application Status is Rejected,' then at least one of the activities 'Examine Trademark Application' or 'Reject Trademark Application' must occur within 0 to 1 days. This introduces an alternative path, allowing flexibility by permitting either the examination to continue or the trademark to be rejected directly.
