## Activities
- **Conduct Survey**: The 'Conduct Survey' activity represents the process of surveying the site or area prior to construction.
- **Design Blueprint**: The 'Design Blueprint' activity involves creating the architectural and structural design plans for the project.
- **Acquire Permits**: The 'Acquire Permits' activity includes obtaining the necessary legal permits required to proceed with construction.
- **Lay Foundation**: The 'Lay Foundation' activity represents the construction of the foundation for the building structure.
- **Construct Framework**: The 'Construct Framework' activity involves building the structural framework of the construction project.
- **Install Utilities**: The 'Install Utilities' activity includes the installation of essential utility systems such as plumbing, electrical, and HVAC.
- **Interior Work**: The 'Interior Work' activity represents the completion of interior finishing and installation tasks.
- **Final Inspection**: The 'Final Inspection' activity involves conducting a thorough inspection of the completed construction project.
- **Handover Project**: The 'Handover Project' activity represents the formal transfer of the completed project to the client or owner.

## Attributes
- **Survey ID: Integer between 1 and 9999**: The attribute 'Survey ID: Integer between 1 and 9999' represents the unique identification number assigned to a survey.
- **Permit Type: Environmental, Zoning, Safety**: The attribute 'Permit Type: Environmental, Zoning, Safety' specifies the category of permit required for the construction project.
- **Foundation Material: Concrete, Reinforced Concrete, Steel**: The attribute 'Foundation Material: Concrete, Reinforced Concrete, Steel' specifies the type of material used for laying the foundation.
- **Utility Type: Plumbing, Electrical, HVAC**: The attribute 'Utility Type: Plumbing, Electrical, HVAC' specifies the category of utility system being installed.
- **Inspection Score: Float between 0.0 and 10.0**: The attribute 'Inspection Score: Float between 0.0 and 10.0' represents the numeric score given during the final inspection to evaluate project quality.

## Binds
- **bind Conduct Survey: Survey ID**: The bind 'Conduct Survey: Survey ID' specifies that the activity 'Conduct Survey' requires the attribute 'Survey ID'.
- **bind Acquire Permits: Permit Type**: The bind 'Acquire Permits: Permit Type' links the 'Acquire Permits' activity with the attribute 'Permit Type'.
- **bind Lay Foundation: Foundation Material**: The bind 'Lay Foundation: Foundation Material' links the 'Lay Foundation' activity with the attribute 'Foundation Material'.
- **bind Install Utilities: Utility Type**: The bind 'Install Utilities: Utility Type' links the 'Install Utilities' activity with the attribute 'Utility Type'.
- **bind Final Inspection: Inspection Score**: The bind 'Final Inspection: Inspection Score' links the 'Final Inspection' activity with the attribute 'Inspection Score'.

## Constraints
- **Init[Conduct Survey] | |**: The 'Conduct Survey' must be the first activity to occur in the process.
- **Precedence[Design Blueprint, Conduct Survey] | | |**: The 'Conduct Survey' activity is permitted to occur only if a 'Design Blueprint' activity has occurred before it within the same process instance.
- **Precedence[Lay Foundation, Acquire Permits] | | |**: The 'Acquire Permits' activity is permitted to occur only if a 'Lay Foundation' activity has occurred before it within the same process instance.
- **Response[Lay Foundation, Construct Framework] | | |0,3,d**: If a 'Lay Foundation' activity occurs, then a 'Construct Framework' activity must eventually occur after the 'Lay Foundation' event at some point in the same process instance, within 0 to 3 days. There is no requirement on what events may occur in between. Multiple 'Lay Foundation' events can be pending at the same time, and a single 'Construct Framework' can fulfill the obligation for all preceding 'Lay Foundation' events. If 'Lay Foundation' does not occur, the constraint imposes no obligation on the occurrence of 'Construct Framework'.
- **Alternate Response[Construct Framework, Install Utilities] | | |0,2,d**: If 'Construct Framework' activity occurs, then 'Install Utilities' activity must occur after that 'Construct Framework' event and before any subsequent 'Construct Framework' occurs, within 0 to 2 days, and no other occurrence of 'Construct Framework' is allowed between a 'Construct Framework' and its corresponding 'Install Utilities'.
- **Precedence[Interior Work, Install Utilities] | | |**: The 'Install Utilities' activity is permitted to occur only if an 'Interior Work' activity has occurred before it within the same process instance.
- **End[Final Inspection] | |**: The 'Final Inspection' must be the last activity to occur in the process.
- **Precedence[Handover Project, Final Inspection] | | |0,1,d**: The 'Final Inspection' activity is permitted to occur only if a 'Handover Project' activity has occurred before it within the same process instance, within 0 to 1 day of that prior occurrence.
