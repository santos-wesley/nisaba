## Activities
- **Request Return**: The 'Request Return' activity represents the initiation of a return process by a customer who wishes to return a purchased item.
- **Approve Return**: The 'Approve Return' activity involves reviewing and authorizing a customer's return request, allowing the return process to proceed.
- **Generate Return Label**: The 'Generate Return Label' activity consists of creating a shipping label for the customer to use when sending the item back.
- **Ship Item Back**: The 'Ship Item Back' activity represents the customer sending the returned item back to the seller or warehouse using the provided return label.
- **Receive Item**: The 'Receive Item' activity involves the seller or warehouse taking possession of the returned item upon its arrival.
- **Inspect Item**: The 'Inspect Item' activity includes examining the returned item to assess its condition and determine whether it meets return criteria.
- **Determine Refund**: The 'Determine Refund' activity involves calculating and deciding the appropriate refund amount based on the inspection results and return policy.
- **Process Refund**: The 'Process Refund' activity represents the execution of the refund payment to the customer through the designated payment method.
- **Restock Item**: The 'Restock Item' activity involves returning the accepted item to inventory for future resale.
- **Dispose Item**: The 'Dispose Item' activity consists of properly discarding or recycling an item that is damaged or unacceptable for restocking.

- **Restock Quantity: integer between 1 and 100**: The attribute 'Restock Quantity: integer between 1 and 100' represents the number of units of the returned item to be restocked into inventory, ranging from 1 to 100.
- **Shipping Cost: float between 0.0 and 50.0**: The attribute 'Shipping Cost: float between 0.0 and 50.0' specifies the cost of shipping the item back, ranging from 0.0 to 50.0.
