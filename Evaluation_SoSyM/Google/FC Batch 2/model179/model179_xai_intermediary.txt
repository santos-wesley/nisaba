## Activities
- **Request Return**: The 'Request Return' activity represents the initiation of a return request by the customer for a purchased item.
- **Approve Return**: The 'Approve Return' activity involves reviewing and approving the customer's return request.
- **Generate Return Label**: The 'Generate Return Label' activity includes creating a shipping label for the customer to return the item.
- **Ship Item Back**: The 'Ship Item Back' activity represents the customer shipping the item back to the company.
- **Receive Item**: The 'Receive Item' activity involves the company receiving the returned item from the customer.
- **Inspect Item**: The 'Inspect Item' activity includes examining the returned item to assess its condition.
- **Determine Refund**: The 'Determine Refund' activity involves deciding the appropriate refund amount based on the inspection.
- **Process Refund**: The 'Process Refund' activity represents issuing the refund to the customer.
- **Restock Item**: The 'Restock Item' activity involves returning the item to inventory for resale if it is in good condition.
- **Dispose Item**: The 'Dispose Item' activity includes disposing of the item if it is not suitable for restocking.

## Attributes
- **Return Status: Requested, Approved, Rejected, Shipped, Received, Inspected, Refunded, Restocked, Disposed**: The attribute 'Return Status: Requested, Approved, Rejected, Shipped, Received, Inspected, Refunded, Restocked, Disposed' specifies the current status of the return process.
- **Item Condition: integer between 1 and 5**: The attribute 'Item Condition: integer between 1 and 5' represents the physical state of the returned item on a scale from 1 to 5.
- **Refund Amount: float between 0.0 and 1000.0**: The attribute 'Refund Amount: float between 0.0 and 1000.0' indicates the monetary amount to be refunded to the customer.
- **Days Since Purchase: integer between 0 and 365**: The attribute 'Days Since Purchase: integer between 0 and 365' represents the number of days elapsed since the original purchase of the item.
- **Return Reason: Defective, Damaged, Wrong Item, No Longer Needed**: The attribute 'Return Reason: Defective, Damaged, Wrong Item, No Longer Needed' specifies the reason provided by the customer for requesting the return.
- **Inspection Score: integer between 1 and 10**: The attribute 'Inspection Score: integer between 1 and 10' represents the score assigned to the item during inspection on a scale from 1 to 10.
